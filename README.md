# iphone-Sales-EDA-project
This project is comprehensive Exploratory Data Analysis on iphone sales data. The goal is to uncover patterns, trends and business insights that can support marketing and strategic decisions.
# Key Analysis Performed :
- Time wise sales trend analysis
- Top-performing iphone models
- Regional sales breakdown
- Correlation between features and sales
- Visuals insights using Matplotlib and Seaborn
# Tools & Libraries used:
- Pandas
- Matplotlib
- Seaborn
- Plotly
